TiDAL Web Flasher

 

Provision a TiDAL

  • 1. Plug the TiDAL in
  • 2. Hold the bottom right button, then tap bottom-left.
  • 3. Release the buttons.
  • 4. Click Connect and click on the badge COM port. The device name should appears as USB JTAG/serial debug unit
  • 5. Select Install TiDAL, and wait.
